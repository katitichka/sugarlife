# Подключение Flutter к Go API

Эта ветка (`feat/go-backend-client`) заменяет обращения приложения к Supabase на HTTP-запросы к проекту `sugarlife_backend`.

## Запуск для разработки

1. В проекте бэкенда запусти PostgreSQL, примени миграцию и импортируй контент по его `README.ru.md`.
2. Запусти Go API командой `go run ./cmd/api`. Для изображений укажи `ASSET_DIR=./assets`.
3. Запусти Flutter с адресом API:

```sh
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8080
```

Для Android Emulator вместо `127.0.0.1` используй `10.0.2.2`. На физическом устройстве нужен адрес компьютера в локальной сети, а Go API должен слушать этот адрес. Для публикации используй HTTPS URL сервера. Адрес задаётся при сборке через `--dart-define`; Supabase URL и ключ приложению больше не нужны.

Локальный HTTP разрешён в Android debug-сборке. iOS разрешает локальные сетевые подключения. Публичный сервер должен работать через HTTPS.

Сессия хранится в защищённом хранилище устройства. Приложение отправляет токен в `Authorization: Bearer ...`; при ответе 401 локальная сессия очищается. При регистрации Go API сразу создаёт профиль.

## Проверка

```sh
flutter analyze
flutter test
```

Проверь вручную: регистрацию, повторный вход после перезапуска, профиль и аватар, список уровней и вопросы, сохранение прогресса, ежедневную карточку, достижения и выход.
